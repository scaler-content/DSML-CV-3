    We open the hood of a CNN. Using only PyTorch tensor operations (no nn.Conv2d, no autograd for the layers), we build one from scratch and see exactly how forward propagation turns an image into class probabilities and how backward propagation turns the loss into gradients that update every layer, to classify MNIST digits 0 vs 1.

    The model we are building
    
  
    
  
    Every layer (Convolutional, Reshape, MaxPool, Dense and the activations) inherits from one base class, Layer, which has two methods:
    
  
    
    
    forward
    input → output
    Takes in the input to the layer and returns the output.
    
    
    backward
    ∂L/∂output → ∂L/∂input
    Takes the gradient of the loss with respect to the layer’s output (output_gradient), updates the layer’s parameters if it has any, and returns the gradient with respect to the layer’s input, which is handed to the previous layer.

  02
  
    Helpers: correlation and convolution
    
  
    Forward propagation is simply feeding the data in the forward direction through the network. Each training image is processed through the convolution, activation, pooling, reshape and Dense layers.
    
  
    The Convolutional layer needs two 2D operations:
    
  
    
    
    “Valid” cross-correlation
    No padding; the output shrinks by kernel_size − 1. Used in the forward pass and for the kernel gradient.
    
    
    “Full” convolution
    The kernel is flipped by 180° and the input is zero-padded so that every partial overlap is counted. Used for the input gradient.
    
  
    
  
    Deep learning libraries call the first operation “convolution” even though it is strictly cross-correlation: the kernel is not flipped. Since kernels are learned, it does not matter.
    
  
    

  
    From slow to fast
    
  
    Step 1, the readable version: slide the kernel over the image with two loops and take “multiply element by element, then sum” at each position.
    
  
    Code: correlate2d_valid_loop
    
  
    Step 2, the same thing without Python loops. unfold gives all sliding windows at once as a tensor of shape (out_h, out_w, kh, kw). Multiplying by the kernel and summing over the last two dimensions is the same “multiply and sum” for every position simultaneously. This is about 100× faster, which matters because it runs thousands of times during training.
    
  
    Code: correlate2d_valid and the sanity check
    
  
    Fast == loop version: True
    
  
    Step 3, “full” convolution: flip the kernel, pad the input with kernel_size − 1 zeros on every side, then do a valid cross-correlation. A 4×4 input with a 3×3 kernel gives a 6×6 output.
    
  
    Code: convolve2d_full
    
  
    Output of full convolution of 4x4 input with 3x3 kernel: torch.Size([6, 6])
    

    

    


    

    
  03
  
    Convolutional layer: forward pass
    
  
    The Convolutional class takes the input_shape = (channels, height, width), the kernel_size, and the depth = the number of kernels (filters).
    
  
    Initialization
    
  
      
    
    • Each kernel has shape (input channels, k, k), so all kernels together have shape (depth, input_depth, k, k).
      • 
    
    • Weights are random, scaled by sqrt(2 / fan_in) (He initialization) so activations do not explode as layers get wider.
      • 
    
    • There is one bias per filter, initialized to 0, like nn.Conv2d.
      • 
    
    • The output shape is (depth, H − k + 1, W − k + 1) (no padding, stride 1).
      • 
  
    
  
    

  
    What the forward pass does
    
  
    It iterates through every filter and every input channel, passes a kernel of the specified size over the image and performs the cross-correlation between kernel and input.
    
  
    
  
    Yi = Bi + Σj=1..n Xj ⋆ Kij,   i = 1 … d
    
  
    Here Y is the output, equal to the bias plus the sum of cross-correlations (⋆) between the input channels Xj and the kernel Kij. In our implementation the bias Bi is a single number per filter, added at every position. In the expanded form, d is the number of filters and n is the input depth.
    
  
    Equations as shown in the lecture
    
  
    In code, for every filter i, accumulate the cross-correlation of each input channel j with its kernel K[i, j], then add the bias.
    
  
    Code: Convolutional (forward)
    
  
    Quick test: one 28×28 grayscale image through 5 filters of size 3×3 gives a (5, 26, 26) output.
    
  
    Code: shape test
    

    

    


    

    
  04
  
    Convolutional layer: backward pass
    
  
    Backward propagation updates the weights and biases of the model with respect to its loss. For a convolution, the learnable parameters are the kernels and the biases; we also need the gradient with respect to the input so it can be passed to the previous layer. Starting from the derivative of the loss with respect to the layer’s output, we compute:
    
  
    • ∂L/∂K and ∂L/∂B, to update the kernels and biases;
    • ∂L/∂X, to hand back to the previous layer.
    
  
    

  
    Three gradients
    
  
    
    
    GradientFormulaCode idea
    
    
      
    ∂L/∂K[i,j]valid cross-correlation of input channel j with output gradient icorrelate2d_valid(input[j], output_gradient[i])
    
      
    ∂L/∂B[i]sum of output gradient ioutput_gradient[i].sum()
    
      
    ∂L/∂X[j]sum over filters i of the full convolution of output gradient i with kernel K[i,j]convolve2d_full(output_gradient[i], kernels[i,j])
    
        
  
    
  
    The bias uses one scalar per filter, added at every position of that filter’s output. By the chain rule its gradient is the sum of the output gradient over all positions of that filter. (The lecture figure shows the special case where the bias has the full output shape; there the gradient is just the output gradient itself.)
    
  
    The input gradient is the output gradient fully convolved with the kernel, that is, fully cross-correlated with the kernel rotated by 180°.
    
  
    Derivations as shown in the lecture
    
  
    
  
    Then a gradient-descent step: parameter -= learning_rate * gradient.
    
  
    Code: the complete Convolutional layer

  05
  
    Activation functions
    
  
    The CNN uses three activations: ReLU, TanH and Softmax. In backpropagation, the gradient arriving from the next layer is multiplied element-wise by the derivative of the activation, evaluated at the layer’s input (chain rule).
    
  
    Code: the Activation base class
    
  
    

  
    ReLU
    
  
    If the input is less than zero, the output is zero; otherwise the output equals the input. ReLU introduces non-linearity. Because it zeroes out every negative activation it produces sparse, “either active or silent” outputs, and helps avoid the vanishing-gradient problems that saturating activations like sigmoid or tanh can run into.
    
  
    f(x) = max(0, x)    f′(x) = 0 if x < 0, 1 if x > 0
    
  
    The derivative f′(0) is not defined, so it is usually set to 0.
    
  
    Code: ReLU
    

  
    TanH
    
  
    TanH takes any input and outputs a value between −1 and 1. The greater the input, the closer the output is to 1; the smaller the input, the closer it is to −1. In practice it is useful when we want the model to converge quickly with a larger learning rate, since it produces stronger gradients than a saturating activation like sigmoid.
    
  
    tanh′(x) = 1 − tanh²(x)   (by the quotient rule)
    
  
    Code: TanH
    

  
    Softmax
    
  
    Softmax is generally the last layer of a network. It converts the classification layer’s outputs to a probability map whose entries sum to 1. Here there are 2 output classes (digit 0 vs. digit 1).
    
  
    With ΣC = Σd ezd so that yc = ezc / ΣC, the derivative of output y with respect to input z is yi(δij − yj). The first part propagates the softmax values down the diagonal, then we subtract the product of softmax values. In matrix form the Jacobian is diag(y) − y yᵀ.
    
  
    Numerical note. exp(z) overflows for large z, so in the forward pass we first subtract max(z) from all inputs. This does not change the result (it cancels in the ratio) but keeps the numbers small. Try the “add a constant” slider in the widget above.
    
  
    Code: Softmax

  06
  
    Max pooling
    
  
    The MaxPool layer selects the maximum pixel value in each kernel area of every image; the filter slides over the image according to the given stride.
    
  
    
  
    Backward propagation
    
  
      
    
    • Only the input elements selected during the forward pass receive gradient; every other index is zero.
      • 
    
    • If several values in a window tie for the maximum (common right after ReLU, which creates many zeros), the gradient goes to just one of them (the first), as PyTorch does. Otherwise the same gradient would be counted several times.
      • 
  
    
  
    
  
    
  
    Vectorized implementation
    
  
      
    
    • Forward: unfold gives all pooling windows; take the max of each window and remember which position inside the window won (argmax).
      • 
    
    • Backward: start from zeros and add each output gradient at the remembered winning position. We add because with stride < kernel size, windows overlap and one input pixel can win in several windows.
      • 
  
    
  
    Code: MaxPool

  07
  
    Reshape and Dense
    
  
    Reshape (flattening)
    
  
    The Reshape layer changes the dimensions of a tensor to a compatible shape using torch.reshape, so convolutional output can be passed through dense layers. For example, a tensor of size (5, 4, 1) becomes (20, 1). In our network, (5, 25, 25) becomes (3125, 1). The backward pass simply reshapes the gradient back.
    
  
    Code: Reshape
    

  
    Dense layer
    
  
    The Dense layer (fully-connected or linear) converts the features learned by the convolutional layers into a feature vector and classifies it, here into 2 classes.
    
  
    Z = W · X + b
    
  
    W is the weight matrix, X the input, b the bias and Z the output. During backpropagation:
    
  
      
    
    • weights gradient = output gradient · transpose of the input (dW = dY·Xᵀ);
      • 
    
    • input gradient = transpose of the weights · output gradient (dX = Wᵀ·dY), computed with the old weights;
      • 
    
    • the weights are updated with the weights gradient and the bias with the output gradient, both scaled by the learning rate.
      • 
  
    
  
    Code: Dense
    
  
    
  
    
  
    

    

    


    

    
  08
  
    The loss function
    
  
    Log loss is the negative mean of the log of the correctly predicted probabilities. It shows how close the predicted probability is to the true value: the more the prediction diverges from the actual value, the higher the log loss.
    
  
    During backpropagation we need the derivative of the loss with respect to the output to compute the gradients of the network. Since the network ends in a Softmax with two outputs and the target is one-hot, we apply this binary log loss to each of the two outputs and average them. We also clip predictions to [ε, 1 − ε] so that log(0) can never produce inf or nan.
    
  
    ∂L/∂y_pred = 1/N · ( (1 − y_true)/(1 − y_pred) − y_true/y_pred )

    Training and evaluating
    
  
    For each training image, train:
    
  
    1. runs the forward pass through all layers (predict);
    2. computes the loss;
    3. starts the backward pass with the loss derivative and walks through the layers in reverse order, each one updating its own parameters and passing the input-gradient back.
    
  
    After every epoch it prints the average loss and the training accuracy.
